# 2. Terminology

Back in the last millennium, we had some clear demarcations on the scale of network connectivity and on the kind of technologies we used at each scale. 
Local Area Networks (LANs) normally spanned a single building or a campus (a group of buildings on the same contiguous site). Although there were many original technologies, Ethernet is now the dominant (and almost sole) technology in use. Modern LANs are expected to have high bandwidth (typically 10Gbps), low latency and very low bit/error rates. 

Metropolitan Area Networks (MANs) were intended to span a large town of city, of the order of 10-20kms. Protocols were developed which worked on local cables or using line-of-sight microwave links. Original MAN technologies had bandwidths in Mbps, medium latency and medium bit/error rates. 
Wide Area Networks (WANs) had coverage of the rest of the country or the rest of the world. Many technologies were used, most of which were based on the old wide area network which existed, the old time-division multiplexing (TDM) telephony network. In TDM, each user is assigned to a time slot; no other station can send in that time slot. If a station has a lot of data to send, it can send only when its time slot comes up, even if all other time slots are empty. If a station has nothing to transmit when its time slot comes up, the time slot is sent empty and is wasted. 
Original WAN technologies had low bandwidths in Kbps or Mbps, high latency and medium bit/error rates. 

Now, fiber optic cables have become ubiquitous both nationally and worldwide. Fibre Optics are characterized by low latency and almost unlimited bandwidth; Letterkenny IT currently has two external connections which are (theoretically!) capable of 1.6Tbs each. This is done by Wavelength Division Multiplexing (WDM), sending a single data stream at 10Gbps on one colour of light and allowing for up to 160 discrete colours. As fibre optic technology spread and carrier networks moved away from TDM, it became cheaper and more efficient to use LAN technologies to interconnect widely dispersed networks. 
In this document, we will briefly discuss the legacy technologies from TDM which you may occasionally come across for specific purposes. We will also discuss the current approaches to WAN connectivity.
