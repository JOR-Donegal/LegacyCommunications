# Point to Point
If you have a DSL circuit at home, you may still use some of this technology! 

Point-to-point protocol (PPP) was intended to establish a direct link between two nodes on a point-to-point link. It allowed for multiple protocols. It supported authentication with Password Authentication Protocol (PAP) or Challenge Handshake Authentication Protocol (CHAP). It also had error detection, encryption, and compression. It was commonly used by ISPs for connections over Ethernet (PPoE) or ATM (PPoA). When setting up dial-up circuits over ISDN, this was used with indication.

For encapsulation, it used High-Level Data Link Control (HDLC). To establish, configure, and test the data link connection, it used Link Control Protocol (LCP). PPP was designed to allow the simultaneous use of multiple network layer protocols and Network Control Protocol (NCP) was used for establishing and configuring these different network layer protocols.

In the late 1900s, we would have taught data communications using serial ports. They have been dropped by most educators now. Its a pity, as you will still come across this technology in Military, Aerospace, Oil and Gas, etc.

Point to Point Protocol over Ethernet (PPP0E) encapsulates PPP packets in Ethernet frames. This technology is still used by ISPs for DSL termination. It is very suited for unbundled services to DSLAMs. It adds 8-byte overhead per packet, which can be very significant for small packets.
